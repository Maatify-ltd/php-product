## Supported versions

Release candidate [`maatify/php-product:1.0.0-rc.1`](https://packagist.org/packages/maatify/php-product#v1.0.0-rc.1) is published on Packagist. There is no supported Stable release line.

## Reporting a vulnerability

Report suspected vulnerabilities privately to [support@maatify.dev](mailto:support@maatify.dev). Keep vulnerability details out of public issues and pull requests. Include the affected commit, the affected capability, and enough information to reproduce the behavior with synthetic data. Remove credentials and private data before sending a report. Coordinate disclosure with the maintainers.

## Scope

This policy covers the package code and schema in this repository. The [Package Reference](PRODUCT_PACKAGE_REFERENCE.md#host-access-and-request-limits) describes the Host's responsibilities for access control and request limits. Report issues specific to a dependency through that dependency's security policy.
